## कार्यकारी सारांश

आधुनिक एंटरप्राइज़ अवसंरचना कई प्रणालियों में बंटी हुई है: पारंपरिक ईआरपी (SAP, Oracle), रिलेशनल डेटाबेस (PostgreSQL, MySQL), मैसेज ब्रोकर्स और तृतीय-पक्ष क्लाउड SaaS। मौजूदा एकीकरण समाधानों में गंभीर चुनौतियाँ हैं:
1. **पब्लिक SaaS iPaaS** (Zapier, Workato, MuleSoft): संवेदनशील डेटा और क्रेडेंशियल्स को बाहरी क्लाउड पर भेजने की मांग करता है, जिससे सख्त डेटा संप्रभुता नियमों (GDPR, HIPAA, SOC 2) का उल्लंघन होता है।
2. **भारी लिगेसी मिडलवेयर**: अत्यधिक महंगे लाइसेंस, वेंडर लॉक-इन और जटिल परिचालन।
3. **घरेलू कस्टम स्क्रिप्ट्स**: वितरित ट्रेसिंग, स्कीमा ड्रिफ्ट डिटेक्शन और मल्टी-टेनेंट अलगाव की कमी।

**FlowMesh इस दुविधा को समाप्त करता है।** यह Python (FastAPI), Go, Next.js 15, NATS JetStream, और PostgreSQL/Redis पर निर्मित एक शून्य-लाइसेंस-लागत, उच्च-प्रदर्शन वाला बैकबोन प्रदान करता है।

| क्षमता | FlowMesh | क्लाउड SaaS iPaaS | पारंपरिक एंटरप्राइज ESB | इन-हाउस कस्टम स्क्रिप्ट्स |
| :--- | :---: | :---: | :---: | :---: |
| **डेटा संप्रभुता** | **100% सेल्फ-होस्टेड** | क्लाउड मल्टी-टेनेंट | ऑन-प्रेमिस | सेल्फ-होस्टेड |
| **फ़ायरवॉल इनबाउंड पोर्ट** | **शून्य (केवल आउटबाउंड mTLS)** | इनबाउंड पोर्ट / बैस्टियन आवश्यक | जटिल VPNs | विविध |
| **निष्पादन सुरक्षा** | **नो रिमोट कोड एक्जीक्यूशन (RCE)** | रिमोट कोड एक्जीक्यूशन संभव | भारी JVM प्लगइन्स | अनियंत्रित स्क्रिप्ट्स |
| **स्टेट इंजन** | **Redis / RediForge / Memory** | ब्लैक-बॉक्स प्रोप्रायटरी | रिलेशनल DB बाधा | कोई स्थिति नहीं |

| **लाइसेंस शुल्क** | **निःशुल्क (Apache 2.0)** | $50,000 - $250,000 / वर्ष | महंगे बहु-वर्षीय अनुबंध | अत्यधिक डेवलपर समय |

## मुख्य क्षमताएं और सिद्धांत

- **शून्य-इनबाउंड अटैक सरफेस ([ADR-0001](docs/adr/ADR-0001-agent-outbound-only.md))**: FlowMesh एज एजेंट केवल आउटबाउंड mTLS/WebSocket टनल के माध्यम से कंट्रोल प्लेन से कार्य प्राप्त करते हैं। ग्राहक के फ़ायरवॉल पर कोई पोर्ट खोलने की आवश्यकता नहीं होती।
- **क्रिप्टोग्राफ़िक रूप से हस्ताक्षरित कमांड ([ADR-0002](docs/adr/ADR-0002-no-remote-code-execution.md))**: रिमोट कोड एक्जीक्यूशन (RCE) पूरी तरह वर्जित है। सभी कार्य Ed25519 हस्ताक्षरों और स्थानीय श्वेतसूची द्वारा सत्यापित होते हैं।
- **प्लग करने योग्य StateStore अमूर्तता ([ADR-0003](docs/adr/ADR-0003-statestore-abstraction.md))**: वितरित लॉक और सर्किट ब्रेकर के साथ Redis, RediForge और इन-मेमोरी बैकएंड का एकीकृत समर्थन।
- **अपरिवर्तनीय वर्कफ़्लो संस्करण ([ADR-0004](docs/adr/ADR-0004-immutable-workflow-versions.md))**: डिप्लॉयमेंट $N+1$ संस्करण बनाता है; चल रहे निष्पादन अपने संस्करण पर समाप्त होते हैं; रोलबैक बिना किसी रुकावट के $N-1$ पर सक्रिय सूचक को स्थानांतरित करता है।
- **लिफाफा एन्क्रिप्शन (Envelope Encryption)**: मास्टर की (KEK) द्वारा टेनेंट डेटा की (DEK) का AES-256-GCM में गतिशील डिक्रिप्शन। क्रेडेंशियल्स कभी भी प्लेनटेक्स्ट में संग्रहीत नहीं होते।
- **सख्त मल्टी-टेनेंसी अलगाव**: `TenantScopedRepository` पैटर्न डेटाबेस के प्रत्येक प्रश्न पर अनिवार्य `tenant_id` लागू करता है।

## क्विकस्टार्ट गाइड

### पूर्वापेक्षाएँ (Prerequisites)
- **Python**: `3.12+` (`uv` या `pip`)
- **Node.js**: `20 LTS+` (पैकेज मैनेजर: `pnpm 9+`)
- **Go**: `1.23+` (एज एजेंट निर्माण के लिए)
- **Docker**: `24+` और Compose `v2+`

### विकल्प A: प्रोडक्शन डॉकर कम्पोज़ स्टैक (अनुशंसित)

```bash
# 1. रिपॉजिटरी क्लोन करें
git clone https://github.com/your-org/flowmesh.git
cd flowmesh

# 2. पर्यावरण कॉन्फ़िगरेशन सेट करें
cp .env.example .env

# 3. डॉकर कम्पोज़ के माध्यम से सभी सेवाएँ प्रारंभ करें
docker compose up -d

# 4. डेमो डेटा, टेनेंट, वर्कफ़्लो और एज एजेंट लोड करें
python seed_demo.py
```
